# Guia Comunitário

Projeto desenvolvido para a disciplina de Desenvolvimento Frontend da UNISUAM.

## Objetivo

Criar uma plataforma simples e acessível para divulgar informações úteis à comunidade, auxiliando moradores na busca por serviços, cursos, oportunidades e contatos de emergência.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Layout responsivo
- Navegação por seções
- Busca de informações
- Cards informativos
- Design moderno

## Publicação

O projeto será publicado no GitHub Pages.
